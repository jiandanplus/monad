# 闪绘 · 真实交易像素据点战：现场演示稿

九个据点，三种兵力，180秒。玩家花指挥点派步兵、坦克或工程师，争夺矿场与能源站；占领带来持续产出，支持下一波攻势。每次调遣都是一笔真实 Monad Testnet 合约交易。

演示前先确认两个地址均有测试 MON，并连接同一合约。发送开局交易，随后翡翠联盟从外滩进攻陆家嘴，赤焰军团从北外滩进攻新天地。分别展示签名、广播哈希、成功回执区块及确认后驻军变化。未经钱包确认、回执未就绪、取消或回退时，界面不会制造战果；没有模拟对手。

步兵低成本削弱驻军，坦克用于突破，工程师接管中立点或增援友军。中央能源站每秒产出3，矿场2、其他1。占点时间影响团队统治分，也影响已加入玩家的指挥点恢复，180秒结束按累计分数决胜。指挥点是局内资源，无代币、下注、奖金池或资金托管。

Monad 的结合体现在高频、可组合的标准 EVM 游戏操作，以及面向并行执行的存储设计。不同地址攻击不同据点、且未占领时，其战斗状态写入互不干扰；本地真实 EVM 读写轨迹已验证这一限定场景。占领改变邻接与资源关系，保留必要依赖。不要将这个证明称为实际网络吞吐量测量。

独立无钱包读端共享相同链上地图，观众可以按交易哈希复核战果。积分和资源按链上时间检查点计算，减少逐秒写链；预期回合ID防止延迟签名影响新局。每笔交易的本机观察耗时只说明这一次观测，不等于网络最终性或 TPS。
